# Hello Cloud Run with Python

Source: [Google Codelabs](https://codelabs.developers.google.com/codelabs/cloud-run-hello-python3)

## Exercise definition

Deploy a Python HTTP service from source and inspect the Cloud Run revision and response.

Follow the linked exercise for its requirements. The checks below define what I want to verify in my attempt; extensions are my additions.

## Before starting

A Google Cloud project with billing enabled, deployment permissions, and Cloud Shell or gcloud. Builds, stored images, and service use may be billable; use a dedicated practice project.

## Checks

- Save the service URL, revision, build result, and response to a request with a changed greeting input.
- Explain the access policy chosen by the source deployment and test the resulting HTTP access.
- Extension: change the greeting, deploy a second revision, and compare responses and traffic assignment.
- Remove the service and its practice image/build storage, or delete the dedicated project; verify cleanup.
