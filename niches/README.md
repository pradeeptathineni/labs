# Niches

I split the corpus by the kind of work I intend to do. Code is one way to use your noggin; explaining and comparing ideas is another.

```text
niches/<niche>/<domain>/<collection>/<lab>/
niches/<niche>/<domain>/<group>/<collection>/<lab>/
```

`group` is one optional navigation step, such as `aws` or `mit`. A collection holds related work; a lab is one meaningful unit. Provider identity stays in each `lab.json`, so a collection can mix sources and a source can appear in several collections.

Use `code/` when executable or declarative implementation is central. Use `study/` when the main work is answering, explaining, and reviewing. A certification is a collection or goal, not a separate kind of work.
